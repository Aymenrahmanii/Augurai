# Looped transformers show up twice in a week as GLM-5.4 lands; Simon Willison ships AI-driven charts for Datasette

## What changed

- **GLM-5.4** is Z.ai's first looped-transformer model: weight-shared layers run several times, giving more depth without more parameters. It is not open weights yet. [Post](https://simonwillison.net/2026/Nov/23/glm-54/) · [HN](https://news.ycombinator.com/item?id=50609685)
- **Seven new models** appeared in the radar, mostly Hugging Face trending entries. Qwen3.8-27B-NariQ-GGUF has the top trending score (91), and Inkling-2-Mini-abliterated-GGUF is a third-party build, so treat it with caution.
- **Rising repos and skills:** [mobile-agent-testers](https://github.com/pierridotite/mobile-agent-testers) runs 20 Claude Code agents on parallel phone emulators. [last30days-skill](https://github.com/mvanhorn/last30days-skill) researches a topic across many sources. [hyperframes](https://github.com/heygen-com/hyperframes) renders video from HTML.
- **MCP:** [AI Visibility Tracker](https://github.com/1alexander-ai/ai-visibility-tracker-mcp) tracks brand mentions across AI assistants.
- No benchmark moves and no promotions today.

## One practice to try today

**Compile a view to a query over all the data.** A chart of one page of rows can mislead. Write the GROUP BY by hand first, then compare it with the first 100 rows. See [the source post](https://simonwillison.net/2026/Nov/23/datasette-charts/).
