## One practice to try today

**Judge an AI tool by how often you have to correct it.** Simon stopped using Claude Code daily because he corrected it too often, and came back when the default result was usually right. Tally your own corrections over a few tasks. Start with the exercise: [source](https://simonwillison.net/2026/Nov/24/llm-inflection-points/).
